# DON BOSCO SAFE
### Student Protection & Anti-Bullying System

Prototipe mobile-first dengan layar utama sederhana dan empat tombol besar:
- **DARURAT** — tekan dan tahan untuk simulasi SOS.
- **LIHAT KEJADIAN?** — lapor cepat sebagai saksi.
- **SAYA DI-BULLY** — pilih jenis perundungan.
- **LOKASI AMAN** — lihat contoh tempat meminta bantuan.

## Menjalankan
1. Ekstrak ZIP.
2. Unggah `index.html`, `README.md`, dan folder `assets` ke root repository GitHub.
3. Aktifkan GitHub Pages melalui Settings → Pages → Deploy from a branch → `main` → `/(root)`.
4. Buka website dari HP untuk tampilan mobile.

## Catatan penting
Ini prototipe front-end untuk demonstrasi, bukan layanan darurat sungguhan. Laporan hanya disimpan sementara di browser; tidak ada backend, database, GPS, akun, atau notifikasi nyata. Penerapan operasional memerlukan backend aman, autentikasi, kontrol akses, push notification, petugas respons, SOP sekolah, dan perlindungan data anak. Jangan mengandalkan prototipe ini saat keadaan darurat aktual; hubungi petugas sekolah atau layanan darurat yang sesuai.
